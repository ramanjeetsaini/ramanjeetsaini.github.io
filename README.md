# Ramanjeet Saini Portfolio

This repository contains the portfolio website for Ramanjeet Saini and is ready to be hosted on GitHub Pages.

## Local preview

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages deployment

1. Create a GitHub repository.
2. Push this repository to GitHub.
3. Open the repository settings.
4. Go to Pages.
5. Select the branch and root folder.
6. Save the settings.

Your site will be published at:

- `https://<github-username>.github.io/<repo-name>/` for a project site
- `https://<github-username>.github.io` for a user/organization site

If you use a user site, the repository name should be `<github-username>.github.io`.
