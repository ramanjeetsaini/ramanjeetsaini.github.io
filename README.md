# Ramanjeet Saini Portfolio

This repository contains a clean, resume-based portfolio website for Ramanjeet Saini, built for GitHub Pages hosting.

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deployment

1. Push this repository to GitHub.
2. Open the repository Settings > Pages.
3. Select the branch and root folder.
4. Save.

The site will be published at:

- https://ramanjeetsaini.github.io

if using the repository name `ramanjeetsaini.github.io`.
